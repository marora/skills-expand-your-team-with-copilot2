# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share activities on WhatsApp, Facebook, or X, or copy a direct activity link

## Sharing an activity

Choose a sharing option on any activity card; no login is needed. Social links
open a new tab so you can review the post before sending. **Copy link** lets you
paste the activity link into a message. If copying is blocked by your browser,
copy the selected link displayed on the card instead.

Opening a shared link highlights and scrolls to that activity. Posts include only
the activity name and link, never participant details. Social networks are only
contacted when you select their sharing links.
