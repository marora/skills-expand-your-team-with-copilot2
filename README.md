## Share school activities

Open the activities website and use **WhatsApp**, **Facebook**, or **X** on any
activity card to share it with friends. These open a new tab where you can review
your post before sending. No teacher login is needed.

Use **Copy link** to share through another app. If automatic copying is unavailable,
copy the selected link shown on the card. Shared links bring friends directly to
the activity. Sharing includes only the activity name and link, not student details;
no social network is contacted until you choose its link.

See the [Development Guide](docs/how-to-develop.md) to run the website.
